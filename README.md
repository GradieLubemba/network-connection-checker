# Network Connection Checker

## Overview
Network Connection Checker is a simple Python project that tests network connectivity to selected websites.

## Features
- Checks connectivity to Google, Microsoft, and GitHub.
- Tests connections through HTTPS port 443.
- Displays the date and time of the test.
- Reports whether each connection is successful or unreachable.

## Technologies
- Python
- Socket library
- Datetime library

## How to Run
Make sure Python is installed on your computer.

Run the following command in your terminal:

```bash
python network_checker.py
```

## Example Output

```text
Checking Google (www.google.com)... CONNECTED
Checking Microsoft (www.microsoft.com)... CONNECTED
Checking GitHub (github.com)... CONNECTED
```
